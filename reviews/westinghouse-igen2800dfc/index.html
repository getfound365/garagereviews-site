Skip it if you need a generator this week: it is out of stock with no arrival date. Skip it if you will not pull a recoil cord: there is no electric start on this model.

Performance in real use

The 98cc engine makes 2,800 peak / 2,200 running watts on gasoline and 2,520 / 1,980 on propane, with a 1.1-gallon tank and up to 12 hours at 25% load on gas — about 0.09 gallons per hour, one of the most fuel-efficient in its class. It is parallel capable, so two of them can be paired for more power, and the TT-30R outlet makes it RV-ready. The CO sensor is included. The noise question is the one honest gap: Westinghouse says 52 dBA, one spec table says 62 dBA at 25% load and 25 feet, and buyers say “very quiet” — the marketing number and the table disagree, so neither is quoted here as a measured fact. Clean power under 3% THD means sensitive electronics are safe on it.

Setup

Recoil start only — three pulls on the first start, per one buyer, then first pull after that. At 45.4 pounds it is a one-person carry to the campsite or the tailgate. Break it in before the trip: one buyer ran it 5 hours at varying loads on propane to break it in, using a quarter tank. The digital display shows fuel level, lifetime hours, remaining runtime, voltage, and frequency. Read the propane setup before the first run: the first start on a new fuel is the wrong time to learn the fuel selector.
