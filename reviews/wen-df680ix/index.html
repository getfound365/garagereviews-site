Performance in real use

The 224cc WEN engine makes 6,800 surge / 5,100 running watts on gasoline and 6,000 / 4,500 on propane, with a 2.9-gallon tank and about 6.1 hours at half load on gas (9 hours on LPG, per Wattroster). At 64 dB at quarter load it is quiet for a generator in this watt class — an RV-park-friendly number, though not silent. As an inverter it makes clean power for sensitive electronics, and it carries 5 outlets. RVContext lists it as its top RV inverter pick. The honest catch, beyond the thin review base, is the start-method conflict in the note above: the listing says electric start in one place and pull cord in another, so confirm the start method with WEN before you buy for someone who cannot pull-start a generator.

Setup

Electric start with a recoil backup, per the listing title and description — but the spec table says “Pull Cord Start,” so treat the start method as unverified until WEN confirms it (see the note above). At 94.8 lb this is a two-person lift onto a truck bed; the wheels and handle help once it is on the ground. Break it in on gasoline or propane before the outage — the first run on a new fuel is the wrong time to learn the fuel selector. A 3-year warranty covers it, per Wattroster.
