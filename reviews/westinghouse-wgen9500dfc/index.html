Performance in real use

The 457cc Westinghouse engine makes 12,500 peak / 9,500 running watts on gasoline and 11,200 / 8,500 on propane, with a 6.6-gallon steel tank and a fuel gauge. Generator Bible's runtime figures are 12 hours at 25% load on gas and 8 hours at 50% — about 0.83 gallons per hour at half load, which it calls somewhat poor fuel efficiency for the class. It is loud for a home generator at 74 dBA — about a vacuum cleaner — so plan the placement away from bedrooms. Remote start comes with a key fob, and the control panel carries 6 AC outlets including the transfer-switch-ready ST Switch outlet. The CO sensor shuts the engine down if carbon monoxide builds up.

Setup

Recoil, electric, and remote start — the key fob is included. At 212 pounds, this is a two-person lift onto a truck bed or a ramp job; the wheels and handle help once it is on the ground, but do not plan to carry it alone. Break it in on gasoline or propane before the outage — buyers who tested it on propane first report it “started up first try.” A transfer switch install needs an electrician; the ST Switch outlet is built for that hookup. And read the propane setup before the storm: the first run on a new fuel is the wrong time to learn the fuel selector.
